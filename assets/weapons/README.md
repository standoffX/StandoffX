# M9 Bayonet skin assets

The game expects these exact local paths:

- `assets/weapons/bayonet_m9_blue_blood.glb`
- `assets/weapons/bayonet_m9_sparkling_gaze.glb`

The original uploaded GLBs are packaged in `StandoffX_Zone9_and_M9_Skins.zip`. Merge the archive's `assets/` directory into the repository root, then commit and push the two models. Keep the filenames unchanged.

The models do not contain authored animation clips; first-person knife wind-up, slash and recovery are animated procedurally in `play2.html`.
